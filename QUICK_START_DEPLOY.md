# Deploy to Railway in 5 Minutes ⚡

## What you'll get
Live app at: `https://your-app.railway.app`
- Full database included
- Auto HTTPS
- Auto-scaling
- Logs dashboard

## Go!

### 1️⃣ Sign up (1 min)
- GitHub account: https://github.com
- Railway account: https://railway.app (sign up with GitHub)

### 2️⃣ Push to GitHub (2 min)
```bash
cd "C:\Users\guest1\production tracker"
git init
git add .
git commit -m "Kiosk tracker ready to deploy"
git remote add origin https://github.com/YOUR_USERNAME/kiosk-tracker
git push -u origin main
```

(First, create empty repo on github.com)

### 3️⃣ Deploy on Railway (1 min)
1. Go to https://railway.app/dashboard
2. "New Project" → "Deploy from GitHub" → Select repo
3. Railway auto-detects Next.js app
4. Add PostgreSQL plugin (click "Add Services" → PostgreSQL)
5. Click "Deploy"

**Done!** ✓

Your app is live in ~2-3 minutes at the URL shown in Railway dashboard.
