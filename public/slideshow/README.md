# Slideshow images

Drop image files in this folder and they appear in the floor slideshow
automatically — both the Slideshow tab and the sleep-mode screen. No code
change or redeploy list to edit.

- Formats picked up: .jpg .jpeg .png .webp .avif .gif
- Order: filename order, so prefix with 01-, 02-… to control the sequence
- The live team leaderboard is always shown as the final slide

Files here are committed to the repo and served publicly at /slideshow/<name>,
so only put pictures here that are fine to be publicly reachable.
